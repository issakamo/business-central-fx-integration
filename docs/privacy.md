# Privacy Statement

This extension retrieves foreign exchange rate data from Frankfurter
(api.frankfurter.dev), a free, third-party service, and writes it into
Business Central's own Currency Exchange Rate table. No personal,
business, or transactional data from your Business Central environment
is sent to Frankfurter or to any other external service — requests
consist solely of a base currency code and a list of target currency
codes.

Frankfurter's own stated policy is that it does not collect or log
personal data, IP addresses, or request URLs.

All integration log data generated by this extension (sync history,
success/failure counts, error messages) is stored entirely within your
own Business Central database.
